# Certification images

Add badge or certificate images for the certifications section:

| File | Certification |
|------|---------------|
| `alteryx-designer-core.png` | Alteryx Designer Core |
| `hackerrank-sql-advanced.png` | HackerRank SQL (Advanced) |
| `apache-airflow-fundamentals.png` | Apache Airflow Fundamentals (Astronomer) |

Use PNG with transparent or white backgrounds. Recommended height: 400–600px. Images are displayed with `object-contain` inside rounded cards.

Paths are referenced in `constants.js` under `CERTIFICATIONS`.
